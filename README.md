# AgentISA-Bench: What Makes a Virtual ISA Programmable by AI Agents?

Controlled study of agent-facing documentation interfaces to one fixed virtual IR (StableHLO).
Status (2026-10-13): implemented, validated and **run**. The paper draft is in `paper/main.pdf`.

## What is here
| Path | Content |
|---|---|
| `REVIEW.md` | Strict review of the original scaffold (all [B]/[M] items fixed) |
| `src/agentisa/fact_inventory.py` | 77 canonical facts (nl + formal renderings), anchored to the pinned spec |
| `src/agentisa/interfaces.py` | Treatments: none, minimal, syntax_only_structured, prose, structured, interactive (+ post-hoc interactive_forced); automated equivalence audit; retrieval tool |
| `src/agentisa/tasks.py` | 38 parametric templates x 4 instances (dev = instance 0, eval = 1-3), numpy oracles, reference solutions |
| `src/agentisa/evaluator.py` | Sandboxed parse/verify (MLIR StableHLO) + XLA:CPU execution with op allow-list |
| `src/agentisa/harness.py`, `models.py` | Trial loop (tools, repairs), OpenAI/Ollama client |
| `src/agentisa/analysis.py` | Paired contrasts, template-cluster bootstrap, exact McNemar, Holm, post-hoc failure taxonomy |
| `docs/PREREGISTRATION.md`, `results/FREEZE.sha256` | Frozen protocol + addendum for the post-hoc condition |
| `data/processed/` | Task manifest, G1 validation (152/152), treatment audit, mutation test |
| `results/` | Trial JSONL + transcripts for all runs, `analysis.json`, post-hoc taxonomy |
| `paper/` | IEEE two-column draft (`main.tex`, figures/tables generated by `scripts/analyze_results.py`) |

## Reproduce
```bash
uv venv .venv --python 3.12 && uv pip install --python .venv/bin/python -r requirements.lock.txt
.venv/bin/python scripts/validate_tasks.py          # gate G1: all reference solutions pass
.venv/bin/python tests/check_fact_examples.py       # all fact code examples verify
.venv/bin/python -m pytest -q tests                 # unit tests
.venv/bin/python scripts/audit_treatments.py        # prose/structured audit + token lengths
.venv/bin/python scripts/mutation_test.py           # oracle sensitivity
OPENAI_API_KEY=... .venv/bin/python scripts/run_experiment.py --provider openai --model gpt-4.1-mini-2025-04-14 --split eval --workers 6
.venv/bin/python scripts/analyze_results.py         # analysis.json + paper tables/figures
```
Main study cost about $5.20 and the post-hoc runs about $1.61 (list prices; 2,394 trials in total).

## Known limitations (also in the paper)
Instance-vs-schema confound in syntax facts between the prose and structured renderings; structured is about 31% longer in tokens;
one model family; failures are almost all static, so the oracle rarely decides an outcome; the fact inventory and audit were authored
with AI assistance and still need an independent human audit; KernelBench/TritonBench conversion has not been done.
